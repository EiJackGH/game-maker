JavaScript is Disabled or Unsupported

Blocks is an interactive web-based IDE that uses JavaScript to run the HTML5 Canvas game engine, script compiler, sprite builder, and level editor. Without JavaScript, game physics and interactive tools cannot run.

How to Enable JavaScript in Your Browser

Google Chrome & Edge

Settings > Privacy and security > Site Settings > JavaScript > Select "Sites can use Javascript".

Mozilla Firefox

Type about:config in the URL bar, search for javascript.enabled, and set value to true.

Apple Safari

Settings > Security tab > Check the box for "Enable JavaScript".

Mobile Browsers

Open browser settings > Site settings / Advanced > Enable JavaScript.

After enabling JavaScript, refresh or click below.
