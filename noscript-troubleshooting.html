Why JavaScript is Required

Blocks Retro Game Maker is a fully interactive, client-side web application. Unlike static sites, the editor and engine rely heavily on browser-native APIs powered by JavaScript.

HTML5 Canvas Engine

Renders tilemaps, sprite graphics, physics updates, and active game loops at 60 FPS directly on standard web canvases.

Web Audio Synthesizer

Synthesizes retro 8-bit sound effects (jumping, coins, damage, victory) dynamically using browser Web Audio oscillators.

Script Sandbox & Analysis

Evaluates visual event rules, custom JavaScript hooks, and performs real-time static code analysis for level validation.

LocalStorage File Manager

Persists level designs, custom block definitions, and user settings seamlessly inside your browser local storage.

How to Enable JavaScript by Browser

Select your web browser below and follow the step-by-step instructions to ensure JavaScript execution is allowed for Blocks.

Google Chrome & Microsoft Edge
  1. Click the three dots menu icon in the top-right corner of your browser.
  2. Select Settings > Privacy and security.
  3. Click Site Settings > JavaScript.
  4. Ensure "Sites can use JavaScript" is selected.
  5. If Blocks is in the blocked list under "Not allowed to use JavaScript", remove it or add it to "Allowed to use JavaScript".
Mozilla Firefox
  1. Type about:config in the address bar and press Enter.
  2. Click "Accept the Risk and Continue" if prompted with a warning banner.
  3. Search for javascript.enabled in the search bar.
  4. If the preference value is false, click the Toggle button to change it to true.
Apple Safari (macOS & iOS)
  1. macOS: Open Safari menu > Settings / Preferences > Security tab. Check the box for "Enable JavaScript".
  2. iOS (iPhone/iPad): Open iOS Settings app > Safari > Advanced. Toggle JavaScript to ON.
Mobile Android Browsers (Chrome / Samsung Internet)
  1. Open Chrome on your Android device > Tap the three dots menu > Settings.
  2. Scroll down and tap Site Settings > JavaScript.
  3. Toggle JavaScript to Allowed / Enabled.

Browser Extensions & Script Blockers

If JavaScript is globally enabled in your browser settings but you still see warning overlays, a privacy extension or ad blocker may be restricting JavaScript execution.

Whitelisting Blocks in Script Blockers

If you use extensions like NoScript, uBlock Origin, uMatrix, or Brave Shield:

  • Click the extension icon in your toolbar while viewing the site.
  • Select "Trust" or "Allow JavaScript globally on this domain".
  • If running locally via file URL or localhost server, allow scripts on localhost or file://.

Frequently Asked Questions

Do exported game web bundles require JavaScript?

Yes. When you export a standalone HTML file using Build Pages Dist, the physics engine, rendering logic, and sound synthesis are bundled into the file using client-side JavaScript.

Does Blocks send any data to external tracking servers?

No! Blocks is 100% client-side and open-source. All your level data, graphics, and custom code stay inside your browser storage without external telemetry or tracking scripts.
